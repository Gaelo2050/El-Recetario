# ElRecetario

**ElRecetario** es una plataforma web donde los usuarios pueden descubrir, compartir y guardar recetas de cocina.  
Permite crear cuentas personalizadas, planificar comidas, acceder a recetas premium y disfrutar de una experiencia moderna y sin anuncios.

## Funcionalidades

- Buscar recetas por ingredientes  
- Explorar recetas destacadas  
- Publicar nuevas recetas  
- Sistema de popularidad/categorías  
- Comunidad de usuarios  
- Diseño adaptable a móvil y desktop

---

## Tecnologías utilizadas

- **Frontend:** HTML5, Tailwind CSS  
- **Backend:** Node.js (Express)  
- **Base de datos:** MariaDB  
- **Autenticación:** Firebase 
- **Pagos:** Stripe
